## 決策紀錄
- 2026-11-10：PWA 的 Service Worker 自己寫，不引入 vite-plugin-pwa（SD ADR-18）。
- 2026-11-09：現金股利與投資費用的分錄用 main（計入收支），買賣交割用 settlement（不計入）；手動報價只影響自己（SD 2.6）。
- 2026-11-09：CSV 改在瀏覽器解析，取消 `import_previews` 暫存集合（SD ADR-17）。
- 2026-11-09：匯入時找不到的帳戶不自動新增，只能對應既有帳戶；分類可自動新增。
- 2026-11-09：圖表改用自製 SVG 元件，不引入 Chart.js（SD ADR-15）。
- 2026-11-09：匯率備援改用 currency-api 官方鏡像；frankfurter.app 沒有新台幣（SD 4.4）。
- 2026-11-09：匯率一律以 TWD 為中介保存，任何本位幣都用交叉匯率（SD ADR-16）。
- 2026-11-09：前端套件採用當下最新主版本：Vue 3.5、Vue Router 5、Pinia 4、Vite 8、Tailwind 4.3、Reka UI 2.11。
- 2026-11-09：平板寬度（640–1023px）與手機相同，使用底部導覽＋「更多」抽屜（SD 5.6 已更新），不另做側邊抽屜。
- 2026-11-09：`npm test` 改用 `node --test "src/utils/*.test.js"`（Node 22 不接受資料夾參數）。
- 2026-11-09：日期欄位採瀏覽器原生 `<input type="date">`，不用 Reka DatePicker（手機體驗較好、不需額外日期函式庫；SD 5.5 已更新）。
- 2026-11-09：預設分類以「該使用者還沒有任何分類」判斷是否建立，不另存 `initialized` 欄位（SD 2.2 已更新）。
- 2026-11-09：本機要用真的 MongoDB 測試時：`docker run -d --name mongo -p 27017:27017 mirror.gcr.io/library/mongo:7`，`MONGODB_URI=mongodb://127.0.0.1:27017/?directConnection=true`。
